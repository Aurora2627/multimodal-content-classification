# Baseline 与主要工作进展

## 定位
ResNet18、CLIP 冻结特征、SigLIP2 冻结特征＋线性/MLP 分类器属于 baseline。主要方法的第一版是双分支残差特征 Adapter，后续重点是严格少样本评估和图文融合错误分析。模型年代和更复杂分类器不能代替有效性验证。

特征 Adapter 在池化向量之后训练，图文编码器保持冻结；不是编码器内部 Adapter、LoRA 或 VLM 指令微调，也不声称原创算法。

## 已完成：CLIP 全量三种子对比
实际从 VS Code 集成终端运行，Apple MPS、Float32、AdamW；种子 42/43/44。训练 1007、验证 305、测试 304；最佳轮次由验证集 Macro-F1 选择。所有种子均报告，均值±样本标准差：

| 模型 | 测试 Macro-F1 |
|---|---:|
| text-linear | 0.5167 ± 0.0128 |
| image-linear | 0.5144 ± 0.0056 |
| fusion-linear | 0.6016 ± 0.0363 |
| fusion-mlp | 0.5713 ± 0.0165 |
| fusion-feature-adapter | 0.5848 ± 0.0263 |

源结果：runs/encoder-adapter-20261008-170145/results.json；三个独立子实验目录名称后缀 clip-s42/43/44。每个子实验有源码快照、环境、输入哈希、日志、五份权重及预测。

当前 Adapter 的均值低于线性融合，不支持“通过 Adapter 提升全量分类”的结论。不能只展示种子 42 的原始 0.6435 当作平均结果。既有测试集已多次使用，这些是探索结果，不是盲测结论。
